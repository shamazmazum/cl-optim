# Changelog

## Version 0.5.1

* Improvement `make-initial-simplex` takes a vector for its second argument `Δ`
  providing more flexible control of initial simplex.
* Improvement `clone` function added to create a vector of `N` elements filled
  with a value `X`.

## Version 0.5

* Add Nelder-Mead optimizer

## Version 0.4

* Incompatible change: MAGICL is replaced with entzauberte-matrices, which works
  with native Common Lisp arrays. As a result `bfgs/magicl` is removed.

## Versions before 0.4

I had no changelog before this point. I am very sorry.
